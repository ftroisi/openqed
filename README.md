# Open QED

Open QED is an open-source software which allows users to simulate light-matter coupled systems using QED.

## Getting started
1. Create and activate a Python virtual environment with at least Python 3.9
2. Clone the code into your preferred location
3. Pip install the repository in an editable: `pip install -e /path/to/repo`
    - If you just want to run it, do not use the `-e` flag
